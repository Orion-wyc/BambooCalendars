# 待办软件功能全景分析

> 分析来源：Microsoft To Do、Todoist、TickTick
> 用途：对照补全 BambooCalendars 功能

## 一、Microsoft To Do 完整功能

### 核心对象
- **清单（List）**：自定义分组，可重命名/删除/排序
- **任务（Task）**：标题、备注、子步骤、截止日期、提醒、重复、重要标记、我的一天、所属清单

### 智能清单
| 名称 | 逻辑 | 状态 |
|------|------|------|
| 我的一天 | 手动添加 + 每日自动建议（重要/过期/当天截止） | ✅ 基本实现 |
| 重要 | 所有标记★的任务 | ✅ |
| 已计划 | 有截止日期的任务，按过期/当天/明天/本周/以后分组 | ❌ 未分组 |
| 任务 | 所有未完成任务 | ✅ |

### 任务操作
| 操作 | 状态 |
|------|------|
| 新建（快捷键 Ctrl+N） | ✅ |
| 编辑标题（点击/快捷键 Ctrl+T） | ✅ |
| 编辑备注 | ✅ |
| 完成/取消完成（点击复选框） | ✅ |
| 标记重要/取消（点击星标/快捷键 Ctrl+I） | ✅ |
| 添加到我的日/移除（Ctrl+K） | ✅ |
| 设置截止日期（快捷键 Ctrl+Shift+T） | ✅ |
| 设置提醒（快捷键 Ctrl+Shift+E） | ✅ |
| 设置重复（每天/工作日/每周/每月/每年） | ✅ |
| 添加子步骤 | ✅ |
| 删除任务（快捷键 Ctrl+D） | ✅ |
| 搜索任务（快捷键 Ctrl+F） | ✅ |
| 拖拽排序 | ✅ |
| 右键菜单（编辑/删除/移动） | ❌ |
| 任务排序选项 | ❌ |
| 内联编辑标题（双击） | ❌ |
