# Bamboo Todo v1.0.0

离线待办事项桌面应用的首个正式版本，参照 Microsoft To Do 的 Fluent 2 设计。

## 功能

- 三栏布局：侧边栏 + 主列表 + 固定宽度详情面板；Unibody 无系统标题栏，窗口按钮由系统原生覆盖层提供
- 智能清单：我的一天（含智能建议）、重要、最近 7 天、日历、任务
  - 日历为月历视图，窗格固定高度最多显示 4 行，超出显示 3 条 + 「更多 N」，点击日期可直接新建任务
- 任务管理：增删改、完成、星标、添加到我的一天、截止日期与提醒、重复（每天/工作日/每周/每月/每年）、子任务与进度条、备注、拖拽排序、优先级 P1-P4、标签
- 搜索与筛选：全局搜索，支持按优先级与标签筛选，在所有视图生效
- 自定义清单：创建、重命名、删除
- 番茄钟：侧边栏切换，右下角浮动面板，时长可调（默认 25/5 分钟）
- 四套主题：浅色、深色、Passion、Passion 深色；自动夜间模式在 19:00-07:00 切换到所选主题对应的深色变体
- 系统通知：提醒到点推送，错过的提醒补发一次
- 离线存储：本地 SQLite 数据库，旧版 JSON 数据自动迁移并归档
- 托盘常驻、全局快捷键、可选的启动时更新检查

## 安装

下载 `Bamboo Todo Setup 1.0.0.exe` 运行安装（Windows x64）。

## 质量

发布前通过 4 时区 Store/Utils 回归、组件层回归、App 编排层回归、SQLite 迁移回归与 Electron 端到端冒烟测试。
