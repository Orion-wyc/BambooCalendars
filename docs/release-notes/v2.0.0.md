# Bamboo Todo v2.0.0 —— 节积而后成高

界面与规划体验的大版本：有机极简设计语言、点状月历与 day sheet、滚轮式时间选择、到期与提醒双通道通知在同一版本落地。数据扎根离线的本地土壤，每完成一个任务就多一枚竹节——v2.0 是其中较粗的一节。

## 亮点

### 有机极简设计
- 大圆角、柔和弥散阴影、1px 微光描边、暖色中性面，图标统一为 Feather 线性风格（`stroke=currentColor`，随主题自动取色）
- 补齐入场动画与面板过渡，遵循 `prefers-reduced-motion`
- 统一最小窗口尺寸与圆角体系；列表操作移入页头，侧边栏精简对齐

### 日历成为规划中心
- 月历重设计：点状紧凑日格（每格最多 10 个优先级色点，实心=待办、空心=已完成）+ `待办|总数` 计数
- 点击日期唤出右侧 day sheet：当日任务清单、就地快捷新建、一键回到今天
- 当日清单已完成项沉底；选中日与今天有独立视觉标识

### 滚轮式时间选择
- iPhone 闹钟式时间滚轮（原生 CSS scroll-snap，一格一停、滚动停止静默归位）
- 统一的日期时间选择器：今天/明天/下周一快捷 chip + 月历网格 + 滚轮，截止日期与提醒共用
- 重复任务的提醒随滚动到下一次发生日续发，不再停留在过去时刻

### 通知升级
- 到期与提醒为独立通道：分别开关、分别测试发送
- 到期于当天 09:00 推送，错过的提醒补发一次，内置去重
- 跨平台适配：Windows 归属 AppUserModelId、macOS 授权请求、Linux 桌面通知

### 主题体系收敛
- 内置主题统一为 Passion / Passion 深色，旧 `theme: light/dark/default/win11-light` 数据自动迁移
- 支持逐主题覆盖中性面（背景/边框/文字令牌），修复表面色覆盖不生效问题

## 改进与修复
- 子任务支持拖拽排序，并可拖到列表最末
- 任务行单行化与步骤行重设计；修复右栏动画闪烁、motion 监听器泄漏、计时器截断
- 关闭输入拼写检查；详情面板底部按钮居中、侧边栏计数对齐
- README 按当前实现重写（SQLite 存储、快捷键全表、测试与 CI、目录结构）；新增 `docs/feature-roadmap.md` 规划 v2.1+ 特性；README 宣传图为日历视图截图（可用 `tests/e2e/screenshot.cjs` 再生成）

## 安装

下载 `Bamboo Todo Setup 2.0.0.exe` 运行安装（Windows x64）。macOS/Linux 可在仓库内 `npm run build:mac` / `build:linux` 自行构建。

## 质量

发布前通过 4 时区 Store/Utils 回归、组件层回归、App 编排层回归、SQLite 迁移回归与 Electron 端到端冒烟测试。

## 升级说明
- v1.x 数据无需处理：存储已是 SQLite，设置与主题旧值加载时自动迁移
- 旧「显示模式」快捷键体系已移除，主题请经 设置 > 主题 或 菜单 视图 > 主题模式 切换
