## 一、TickTick 简介

TickTick 是一款全功能任务管理器，支持 Windows 平台，面向个人和团队效率。它结合了任务管理、日历、番茄钟、习惯追踪等多项功能。

## 三、TickTick 特有且值得移植的功能

### P0 - 最高价值
1. **优先级 P1-P4** — 比二元"重要/不重要"更精细，实现成本低
2. **最近7天视图** — 快速查看近期任务，实现简易（基于已有 planned 分组）
3. **过滤器** — 按优先级/清单/日期筛选任务

### P1 - 中等价值
4. **标签系统** — 跨清单的灵活分组
5. **番茄钟** — 专注计时器，与待办天然结合
6. **日历视图** — 月/周/日展示任务

### P2 - 锦上添花
7. **习惯追踪** — 每日打卡
8. **任务计时** — 统计任务耗时
9. **默认提醒设置** — 新任务自动带提醒

## 四、与现有功能差异对比总结

| 维度 | TickTick | BambooCalendars 现状 | 缺口 |
|------|----------|---------------------|------|
| 任务模型 | 文本/优先级/标签/清单/日历/附件 | 文本/清单/截止日期/重复/子任务 | 优先级/标签/附件 |
| 视图 | 列表/今天/7天/日历/看板 | 列表/我的一天/重要/已计划 | 7天/日历/看板 |
| 效率工具 | 番茄钟/习惯/计时/白噪音 | 无 | 4 个功能 |
| 协作 | 共享/分配/评论/活动 | 无（离线设计） | 全部（不适用） |
| 个性化 | 主题/颜色/字体 | 主题配色/模式/字体缩放 | 标签颜色/默认提醒 |
