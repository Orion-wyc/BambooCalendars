# Bamboo Todo v2.0 桌面界面重设计

> 版本：v2.0（纯 UI 重构，不新增功能、不改数据结构与主题 ID）
> 设计基准：`output/todo-example.webp`（有机极简 / 柔和暗色生产力工具）
> 目标：以有机极简主义（Organic Minimalist）重塑桌面三栏体验，全面提升视觉层级与操作舒适度

---

## 1. 范围与约束

| 维度 | 决策 |
|------|------|
| 功能 | 不变。仅重构呈现层（CSS + 组件 markup + 图标） |
| 数据结构 / 主题 ID | 不变。`light / dark / passion / passion-dark` 保持，自动夜间逻辑不动 |
| 测试契约 | 全部保留。169 项 e2e、假 DOM 组件层、Store/App/迁移逻辑均须绿 |
| 被钉死的值 | `--sidebar-bg`（浅 `#f3f3f3` / 深 `#202020`）、深色主题实底状态按钮 `--success-btn:#107c10`/`--danger-btn:#c50f1f`/`--on-success:#fff`、Passion 状态色、`.cal-cell` 高 134px、紧凑侧栏 ≤80px、侧栏图标中心对齐（依赖各行的 `padding + 3px 指示条占位` 一致） |

## 2. 设计语言

- **大圆角**：卡片/输入 12px，容器 16px，模态 22px，胶囊 `999px`
- **柔和弥散阴影**：三级 `--shadow-sm/md/lg`，低透明度暖黑，去掉任务行 `translateY` 跳变，改用边框 + 阴影过渡
- **暖色中性面**：浅色底 `#f7f6f2` + 白卡片；深色为暖炭墨绿，文字偏暖白
- **Feather 线性图标**：`src/js/icons.js` 内联 SVG，`stroke=currentColor`，随主题取色；**装饰性图标 `pointer-events:none`**，保证点击与 `elementFromPoint` 落到宿主可交互元素
- **三栏体验**：pill 式侧栏导航（圆角选中 + 主题色指示条）、卡片化任务行、右侧详情 sheet（虚线卡片 + 快捷 chip）

## 3. 主题令牌分层

`Theme.apply()` 分两类注入：

1. 品牌/状态色（`--primary/--accent/--success/...`、`--sidebar-*`）——原有机制
2. **中性面 `colors.surfaces`**（新增）：`bgMain/bgPanel/bgHover/bgActive/border/borderLight/borderSoft/textPrimary/textSecondary/textMuted`

`SURFACE_KEYS` 逐一 `setProperty/removeProperty`，缺省回退 `:root` 或 `html.dark-mode`，因此不影响被钉死的 sidebar/status 令牌。**深色模式**接入 `surfaces` + 鼠尾草强调色 `#4f7048 / #7fa37a`，成为 v2.0 旗舰观感。

## 4. 组件改动要点

- **Sidebar**：用户区圆形 avatar 徽标；搜索框加前导图标与聚焦 ring；导航/清单行统一 40/38px、`border-radius 10px`、`::before` 指示条（透明态仍占 3px 以维持图标对齐）；清单分区标题右侧新增“新建清单”快捷 +；行内操作按钮 hover 显现
- **TaskList**：头部加图标徽章 + 径向强调底纹；任务行卡片化、右侧 hover 显“我的一天/重要”动作、meta 用线性图标（旗标/清单/备注/标签）；已完成分区折叠；空状态/建议区去 emoji
- **TaskDetail**：标题区改为虚线 sheet + 我的一天/重要 chip；分节标题与字段标签前导图标；步骤/复选/删除按钮图标化；底部完成/删除按钮带图标
- **Pomodoro**：线性进度条改为**环形进度**（`stroke-dashoffset`），面板与会话统计图标化
- **Settings/Dialog/Contextmenu**：关闭按钮与标签删除图标化，模态/下拉统一大圆角与柔和阴影；日历格内容收紧行高避免溢出
- **TitleBar**：原生控制按钮取色改为读 `--sidebar-bg/--sidebar-text`，与一体式标题栏底色一致

## 6. 取舍

- 参考图为深色鼠尾草方案，但本应用为多主题且浅色为默认；故将“有机极简设计系统”（圆角/阴影/图标/布局）贯穿所有主题，深色模式承载鼠尾草旗舰配色，避免破坏既有主题契约与浅色可用性
- 未引入毛玻璃/Acrylic 大面积使用，仅模态遮罩 `backdrop-filter: blur()` 轻量点缀，兼顾性能与跨平台一致性
